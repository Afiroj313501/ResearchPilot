# 🚀 ResearchPilot AI

AI-powered research intelligence platform built with PERN, RAG, PostgreSQL/pgvector, and Gemini.

## 🎯 Vision

ResearchPilot helps researchers understand, search, compare, and interact with academic papers using retrieval-augmented generation.

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL
- pgvector
- Prisma

### AI
- Gemini API
- Embeddings
- RAG
